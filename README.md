# AI Video Workflow

An open-source collection of prompt chains, automation scripts, and cloud-ready templates designed to help solo content creators automate short-form video production (Instagram Reels & YouTube Shorts) without complex local setups.

## Features
- **Automated Scripting:** Structured prompt templates for generating high-retention hooks and short-form scripts.
- **Visual & Rendering Pipeline:** Streamlined workflows connecting AI video generation tools and editors.
- **Zero-Setup Cloud Execution:** Designed to run directly inside browser-based environments like GitHub Codespaces, making it accessible even from mobile devices.
